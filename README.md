# IBM Data Science Capstone Project
## SpaceX Falcon 9 First Stage Landing Prediction

### Project Overview

This project is part of the IBM Data Science Capstone Project. The objective is to analyze SpaceX Falcon 9 launch data and predict whether the first stage of the Falcon 9 rocket will successfully land.

Successful first-stage landings allow SpaceX to reuse rockets and significantly reduce launch costs. In this project, data science and machine learning techniques are used to understand the factors affecting landing success and build predictive models.

### Project Objectives

- Collect SpaceX launch data using the SpaceX API.
- Collect additional launch data through web scraping.
- Clean and prepare the collected data.
- Perform exploratory data analysis (EDA).
- Analyze the data using SQL.
- Visualize launch sites using Folium.
- Build an interactive dashboard using Plotly Dash.
- Train machine learning models to predict first-stage landing success.
- Evaluate and compare the performance of different machine learning models.
